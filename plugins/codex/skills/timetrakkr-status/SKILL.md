# Time Trakkr status

Run this one command and nothing else. The path is relative to the directory
this `SKILL.md` is in; if `timetrakkr` is on the `PATH`, `timetrakkr status`
is the same thing.

```sh
../../bin/timetrakkr status
```

Show the person what it printed, as it is, in a code block. If a line says
something is wrong, add one sentence saying what to do about it. If the
command is refused because it needs network access, say so.
